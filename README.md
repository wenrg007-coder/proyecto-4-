🔍 Overview

This project focuses on manual multiplatform testing for the Urban Scooter application, validating its behavior across web, mobile, and API layers.
The goal was to ensure functional correctness, compatibility, and consistency of the user experience across different environments.

This repository demonstrates:

End-to-end QA thinking

Cross-platform testing skills

Structured test documentation

Professional bug reporting
